# 📐 Архитектурный план: Школьный Git-форж (Gitea) на Raspberry Pi 5

## 🎯 Цели проекта
Создание полностью локального, надежного и независимого от внешних облаков Git-сервиса (форжа) на базе **Gitea** для «Умной Школы». Система предназначена для обучения учащихся основам командной разработки, контролю версий и автоматической сдаче учебных проектов в изолированной школьной сети.

---

## 🛠 Аппаратная спецификация (Hardware Topology)

| Компонент | Спецификация | Назначение |
|---|---|---|
| **Вычислительный узел** | Raspberry Pi 5 (8 GB RAM, Quad-Core ARM Cortex-A76 @ 2.4 GHz) | Основной хост сервиса Gitea и PostgreSQL |
| **Накопитель (ОС & Данные)** | NVMe SSD 512 GB (через M.2 HAT) или High-End MicroSD V30 128 GB | Хранение Git-репозиториев, снимков БД и системных логов |
| **Охладжение** | Active Cooler for Raspberry Pi 5 | Отвод тепла при высокой нагрузке во время уроков |
| **Питание** | Официальный БП 27W USB-C PD | Стабильная работа при подключении внешних дисков |
| **Сеть** | Gigabit Ethernet (1000 Mbps) / Локальная Wi-Fi сеть школы | Локальный доступ без выхода во внешний интернет |

## 🔐 Модель прав и ролей (RBAC)

1. **Администраторы (Учителя / IT-отдел школы)**:
   - Полный доступ к панели администрирования Gitea.
   - Управление школьными организациями (`class-9a`, `class-10b`, `robotics-club`).
   - Создание и аудит учетных записей учащихся.
2. **Пользователи (Ученики)**:
   - Создание личных репозиториев для выполнения домашних заданий.
   - Работа с веточками (`feature-branches`), отправка Pull Request'ов в репозитории класса.
   - Участие в командных проектах.
