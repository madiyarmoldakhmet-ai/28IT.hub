# 📖 Правила публикации и регламент работы в Wiki (28IT.hub)

Данное руководство содержит обязательные стандарты организации репозиториев, работы с ветками и оформления документации для учеников и преподавателей в школьном Git-форже **28IT.hub**.

---

## 📌 1. Правила наименования репозиториев

Все учебные и проектные репозитории должны следовать единому формату наименования:

$$\text{Формат: } \texttt{фамилия-название\_проекта}$$

### Примеры:
- `ivanov-smart_greenhouse` — проект Иванова по умной теплице.
- `petrov-neural_classifier` — исследовательский проект Петрова по нейросетям.
- `sidorov-calculator_app` — домашнее задание Сидорова.

> [!IMPORTANT]
> Использование кириллицы, пробелов и специальных символов в названиях репозиториев строго запрещено. Используйте только латинские буквы в нижнем регистре (`a-z`), цифры (`0-9`), дефисы (`-`) и нижние подчеркивания (`_`).

## 🌿 2. Регламент работы с ветками (Git Branching Model)

1. **Ветка `main`**:
   - Содержит только протестированный, стабильный и рабочий код проекта.
   - Прямой `git push` в ветку `main` отключен (сдача работ происходит исключительно через **Pull Request**).
2. **Ветки разработки `feature/<название>`**:
   - Любая новая функция, исправление или этап работы разрабатываются в отдельной ветке.
   - Формат наименования: `feature/sensor-reading`, `feature/ui-login`, `fix/bug-timeout`.

### Цикл работы над задачей:
```bash
# 1. Создание новой ветки от main
git checkout main
git pull origin main
git checkout -b feature/camera-stream

# 2. Фиксация изменений
git add .
git commit -m "feat: добавлена функция получения кадров с камеры"

# 3. Отправка ветки на сервер и создание Pull Request
git push origin feature/camera-stream
```

## 📝 3. Стандартный шаблон README.md для школьного проекта

Каждый репозиторий **обязан** содержать файл `README.md` в корневом каталоге, оформленный по данному шаблону:

```markdown
# 🚀 [Название проекта]

Короткое и понятное описание проекта в 2-3 предложениях. Укажите цель создания и решаемую задачу.

## ⚙️ Инструкция по запуску

### 1. Клонирование репозитория
\`\`\`bash

cd ivanov-smart_greenhouse
\`\`\`

### 2. Установка зависимостей
\`\`\`bash
pip install -r requirements.txt
\`\`\`

### 3. Запуск приложения
\`\`\`bash
python main.py
\`\`\`
```
